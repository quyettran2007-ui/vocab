Cách thêm từ vựng mới

Đưa từ vựng cho AI kèm prompt bên dưới. AI trả về một object JavaScript. Dán object đó vào mảng VOCAB (tìm dòng const VOCAB = [).

Prompt mẫu để đưa cho AI:

Tạo dữ liệu từ vựng theo đúng format JavaScript object sau (chỉ trả về object, không giải thích, code không cần dấu ngoặc vuông đầu cuối). Từ cần tạo: [ĐIỀN TỪ VÀO ĐÂY].

Yêu cầu:
- pos: loại từ (noun / verb / adj / adv / phrase...)
- level: trình độ CEFR (A1, A2, B1, B2, C1, C2)
- wordforms: các dạng của từ, mỗi dạng gồm pos (loại từ) và word
- collocations: mỗi cụm gồm en (tiếng Anh) và vi (dịch tiếng Việt)
- example: gồm en (câu ví dụ) và vi (dịch câu đó)
- date: ngày hôm nay định dạng "YYYY-MM-DD"

{
  word: "resilient",
  ipa: "/rɪˈzɪliənt/",
  pos: "adj",
  level: "C1",
  vn: "kiên cường, bền bỉ, mau phục hồi",
  wordforms: [
    { pos: "adj", word: "resilient" },
    { pos: "noun", word: "resilience" },
    { pos: "adv", word: "resiliently" }
  ],
  synonyms: ["tough", "hardy", "adaptable"],
  collocations: [
    { en: "resilient economy", vi: "nền kinh tế vững vàng" },
    { en: "emotionally resilient", vi: "vững vàng về cảm xúc" }
  ],
  example: {
    en: "Children are often remarkably resilient in the face of hardship.",
    vi: "Trẻ em thường rất kiên cường khi đối mặt với khó khăn."
  },
  topic: "Personality",
  date: "2026-07-09"
}

Cách dán vào code

  1. Mở file HTML bằng trình soạn thảo (VS Code, Notepad++...).
  2. Tìm dòng const VOCAB = [.
  3. Dán object mới vào, nhớ dấu phẩy , ngăn cách giữa các từ.
  4. Lưu file, mở lại trên trình duyệt — từ mới xuất hiện ngay.

Các trường dữ liệu:

  • word — từ tiếng Anh (bắt buộc)
  • ipa — phiên âm
  • pos — loại từ: noun, verb, adj, adv, phrase...
  • level — trình độ CEFR: A1–C2 (để lọc & hiện huy hiệu)
  • vn — nghĩa tiếng Việt (bắt buộc)
  • synonyms — mảng từ đồng nghĩa
  • wordforms — các dạng của từ, mỗi dạng có pos và word
  • collocations — mảng cụm, mỗi cụm có en và vi
  • example — object có en và vi
  • topic — chủ đề (để lọc)
  • date — ngày thêm "YYYY-MM-DD" (phân loại theo thời gian)

Ghi chú: định dạng cũ (collocations/example dạng chuỗi text, thiếu level) vẫn chạy được bình thường.
